# تطبيق وَسْم

> تطبيق ويب لإضافة شعار وقالب على الصور بشكل جماعي  
> أحد مبادرات **جمعية ركاز الشبابية** بمحافظة القويعية  
> للتواصل: 0540200621

---

## هيكل المشروع (التطبيق الحالي)

| الملف | الوظيفة |
|--------|----------|
| `index.html` | واجهة التطبيق الرئيسية |
| `script.js` | منطق معالجة الصور وإدارة الواجهة |
| `style.css` | تنسيق تطبيق وَسْم |
| `manifest.json` | إعدادات PWA |
| `service-worker.js` | دعم العمل بدون إنترنت |

## ملفات مؤرشحة للحذف (من مشروع سابق)

| الملف | السبب |
|--------|--------|
| `styles.css` | مكرر - كان خاصاً بنظام الطوابير القديم |
| `app.js` | نظام إدارة طوابير - مشروع منفصل |
| `server.js` | خادم طباعة WiFi محلي - مشروع منفصل |
| `vision2030.png` | صورة غير مستخدمة |

## ميزات التطبيق

- ✅ تحميل صور متعددة دفعة واحدة
- ✅ إضافة شعار بحجم وموضع وشفافية مختلفة
- ✅ إضافة قالب مع التحكم بالشفافية
- ✅ معاينة حية مباشرة
- ✅ تحميل تلقائي متوافق مع iOS / Android / PC
- ✅ تطبيق PWA يعمل بدون إنترنت
- ✅ حفظ الإعدادات تلقائياً

## طريقة الاستخدام

1. افتح التطبيق من أي متصفح
2. اختر صورك (تدعم JPEG / PNG)
3. اختر الشعار (PNG) واضبط الحجم والموضع
4. اختر القالب (اختياري) واضبط شفافيته
5. اضغط "بدء معالجة الصور" وستُحمل جميع الصور تلقائياً
